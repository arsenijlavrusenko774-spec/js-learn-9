# Практическая работа №9 — финальная

## Клиент-серверное приложение: REST API каталога книг

В этой работе браузерный интерфейс уже подготовлен. Ваша основная задача — реализовать серверный API в `student-template.js`.

## Установка и запуск

```bash
npm install
npm start
```

После запуска откройте:

```text
http://localhost:3000
```

## Автоматическая проверка

```bash
node tests.js
```

или:

```bash
npm test
```

Проверяются API-маршруты, status codes, query-поиск, создание, изменение, удаление и ошибки `404/400`.

## Не изменяйте

- имена маршрутов;
- начальные данные без необходимости;
- `module.exports = app`;
- `server.js` и `tests.js`.

## Что сдаётся

Ссылка на GitHub-репозиторий с проектом. Перед сдачей убедитесь, что выполняются `npm install`, `npm start` и `npm test`.
